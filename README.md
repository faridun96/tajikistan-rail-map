# Железные дороги Таджикистана — 3D-карта (three.js)

Интерактивная карта по чертежу `Барои исправления Давронбой.dwg` на реальном рельефе Таджикистана.

Сайт: https://faridun96.github.io/tajikistan-rail-map/

## Как открыть локально

Нужен любой локальный веб-сервер (из `file://` браузер не загрузит модули и рельеф):

```bash
python -m http.server 5178
```

и открыть http://localhost:5178

Ссылки на конкретное место: `#s=Худжанд` (станция), `#l=south` (участок: north, center, south), `#v=country` (вся страна).

## Управление

- перетаскивание — сдвиг, правая кнопка — поворот, колесо — масштаб
- клик по станции — карточка: пикетаж, высота над уровнем моря, соседние станции и расстояния
- клик по участку в легенде — показать только его
- «Вся сеть» / «Вся страна» — общий вид
- `/` — поиск (понимает и таджикские буквы: «Ҷабор» = «Чабор» = «Джабор»), `Esc` — закрыть карточку

## Что откуда взято

| Данные | Источник |
|---|---|
| Пути, станции, названия, пикетаж, км-отметки, пикеты | чертёж DWG |
| Координаты станций (привязка к местности) | OpenStreetMap, таблица `tools/stations-geo.json` |
| Рельеф (высоты) | AWS Terrain Tiles (SRTM и др.), zoom 9 ≈ 240 м |
| Граница Таджикистана | OpenStreetMap (отношение 214626) |
| Пункты «Сархад» | точки пересечения пути с госграницей по OpenStreetMap |
| Границы соседних стран между собой | Natural Earth 1:10 млн |

На чертеже участки сдвинуты друг к другу (схема), поэтому каждый отрезок пути между соседними станциями
переносится на местность отдельно: станции встают точно на свои координаты, форма пути между ними — как на чертеже.

- Участков три: Северный, Центральный, Южный.
- Станции за пунктами «Сархад» (Бекобод, Кудукли — Узбекистан) не считаются нашими: путь к ним показан серым пунктиром.
- Станция на ПК 58+660 без подписи на чертеже — это Ҷабор Расулов (задано в `tools/stations-geo.json`).
- Длины — по геометрии на местности; расстояния между станциями — по пикетажу, если он есть у обеих.

## Обновление данных

```bash
cd tools
npm install
node build-data.mjs      # чертёж -> data.js
node build-terrain.mjs   # рельеф -> terrain.png (нужен только при смене охвата карты)
```

- Названия, цвета и ветки участков — массив `SECTIONS` в `tools/build-data.mjs`.
- Координаты станций, переименования и «чужие» станции — `tools/stations-geo.json`.
