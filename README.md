# Железные дороги Таджикистана — 3D-карта (three.js)

Интерактивная карта, построенная по чертежу `Барои исправления Давронбой.dwg`.

## Как открыть

Нужен любой локальный веб-сервер (из `file://` браузер не загрузит модули):

```bash
python -m http.server 5178
```

и открыть http://localhost:5178

Ссылки на конкретное место: `#s=Худжанд` (станция), `#l=kulob` (участок: north, isfara, center, link, south, kulob, regar).

## Управление

- перетаскивание — сдвиг, правая кнопка — поворот, колесо — масштаб
- клик по станции — карточка (пикетаж, соседние станции, расстояния)
- клик по участку в легенде — показать только его
- `/` — поиск, `Esc` — закрыть карточку

## Обновление данных после правок чертежа

```bash
cd tools
npm install
node build-data.mjs
```

Скрипт читает DWG (LibreDWG/WASM), разворачивает блоки и пишет `data.js`.
Названия участков и их цвета задаются в массиве `SECTIONS` в `tools/build-data.mjs`.

## Что взято из чертежа, а что нет

- Из чертежа: геометрия путей, 44 кружка-станции, названия, пикетаж, км-отметки и пикеты (массивы черточек).
- Длины — по геометрии чертежа (1 единица ≈ 1 м), это длины по схеме.
- Рельеф и названия областей — декоративные, в чертеже их нет.
